# UI 统一整改计划

## 目标

让 16 个页面、所有弹框和常用交互控件复用一套语义 Token 与 Foundation 组件；统一尺寸、状态、主题和键盘操作，并清理重复的页面样式覆盖。

## 阶段与优先级

### P0：Foundation 基础组件与交互

- [x] 清点页面、现有 CSS Token、共享页面头部、按钮类和弹框入口。
- [x] 建立 `Button` / `IconButton`、`TextField` / `TextArea`、`Card`、`DialogLayer` 公共组件。
- [x] DialogLayer 统一 Escape、Tab 焦点循环、焦点返回、背景点击关闭和滚动锁定；用顶层栈处理弹框内再弹确认框。
- [x] 迁移全局壳层、确认/输入框、创建弹框、命令面板和知识库/任务/日程/收件箱弹框。

### P1：页面迁移与组件一致性

- [x] 按功能群迁移 Overview/Today/Tasks/Inbox 与 Notes/Projects/Checklists/Templates 的主要按钮和空状态操作。
- [x] 再迁移 Schedule/Knowledge/Documents/Settings/Plugins/Sparks/Archive/Trash 的主要按钮和常见行操作。
- [x] 统一任务/灵光/归档筛选、日程视图、编辑模式和顶部空间切换；单选列表项统一选中、悬停和键盘焦点状态。
- [x] 23 处列表空状态与编辑/详情占位、设置 Toast 和 PDF 预览加载状态使用共享反馈组件；危险、禁用和焦点状态由共享 Button/控件承接。
- [x] 将笔记、知识页、清单和模板的编辑字段接入共享字段；标题、正文和清单行保留编辑器需要的专属外观。
- [x] 将所有常见主按钮、次按钮、小按钮和文本操作迁移到共享 Button；保留列表行、切换器和步骤操作的业务语义。

### P2：Token 收敛与旧样式清理

- [x] 建立语义表面、文字、分隔线、聚焦、状态色，以及字号/行高、间距、圆角、控件高度、阴影和层级 Token。
- [x] 将重复出现的灰阶文字、选中/悬停表面、弱强调色和聚焦边线接入语义 Token。
- [x] 将常用字体尺寸与行高、`gap` 间距及圆角从页面字面值迁入 Token；间距归并到 1/2/4/8/12/16/20/24/28/32px，圆角归并到 4/6/8/10/12/16/20px，圆形和无圆角也使用专用 Token。
- [x] 将 margin/padding 中 1–34px 的常见正值及 40–88px 的页面留白迁入间距 Token，并归并到统一栅格等级。
- [x] 任务状态、优先级、模板/内容类型、同步状态及错误反馈使用状态 Token；删除重复的深色状态覆盖，改由深色 Token 提供同一语义的颜色。
- [x] 盘点并统一响应式媒体查询断点；主断点按 Large ≥1200、Expanded 840–1199、Medium 600–839、Compact <600 统一。CSS 媒体条件不能引用自定义属性且项目未配置 PostCSS custom-media，因此在 `app.css` 集中说明断点来源；保留 1080px 侧栏适配点和 480px 窄屏控件点。
- [x] 将页面中性文字、控件/面板边框和常用强调色接入语义 Token；项目/搜索类型、OCR、AI 错误、同步冲突、插件安全、灵感阶段等状态改用状态 Token。扩展 40–88px 间距 Token，归并页面留白和弹框贴边负边距；保留搜索输入避让按钮的内边距及品牌横幅/预览色等有意设计。
- [x] 删除被覆盖的旧声明和重复的暗色主题例外规则。
- [x] 确保深浅主题对所有表面、表单、状态标签和危险操作生效。

### P3：边界复核与交付

- [x] 逐页复核 320px、800×600、1440px 及超宽视口布局。
- [x] 复核 150% 字体放大、长文案、窄按钮组、滚动弹框、输入焦点和底部操作区。
- [x] 汇总 8 大维度与 17 项验收状态；记录尚未解决的例外。

## 执行记录

- P0 已完成：新增共享控件和 DialogLayer；确认框、输入框、创建弹框、命令面板及四类常用编辑弹框已接入。
- P1 已完成：16 个页面继续共用 `PageHeader`；主要创建、导入、空状态、保存及常见小操作已迁移到 `Button`，Overview 卡片使用 `Card`；设置页、项目详情、笔记/知识页、清单和模板字段接入共享输入组件。7 组筛选、视图与空间切换接入 `SegmentedControl`，4 类单选列表接入 `SelectableListItem`，23 处列表空状态与编辑/详情占位接入 `EmptyState`，Toast 与 PDF 预览加载接入共享反馈组件。
- P2 已完成：常见文字、表面、分隔、聚焦颜色和状态色已接入语义 Token；页面字号、行高、`gap`、圆角、440 处 margin/padding 数值、40–88px 页面留白和主响应式断点已迁移到统一体系。命令面板也接入共享圆角、字号、控件高度与间距 Token；弹框负边距跟随弹框内边距。深浅主题中的面板表面、表单焦点、状态标签、危险操作及日历今日状态已统一使用主题 Token；品牌横幅/灵感介绍、类型图标和代码预览保留专用颜色。
- 发现并处理嵌套弹框焦点问题：只有最上层弹框消费 Escape/Tab，确认框关闭后将焦点交还原弹框。
- 本轮清理 `app.css` 中已被共享控件覆盖的按钮、搜索框、弹框和勾选圈尺寸；删除与基础 Token 相同的深色提示框、命令列表、状态文字等重复覆盖，同时保留深色专属表面、焦点和品牌例外。未运行构建或测试。
- 本轮静态复核确认主题变量已覆盖主要面板表面、表单焦点、状态标记和危险操作，并清除深色 Token 中重复的 `--field`、`--field-border`、`--hover` 声明；深色总览和聚焦状态弹框已做截图复核。
- 本轮运行时逐页复核 320×800、800×600、1440×900、2560×1440 共 16 个页面：页面级横向溢出均已清除，超宽屏主内容保持 1440px 限宽；发现并修复页面栈自动轨道、日程日期栏及设置同步区的窄屏溢出。日程周网格保留在日历面板内横向滚动。
- 弹框运行时复核已覆盖收件箱记录、任务、笔记和项目创建弹框；任务弹框在 320×600/800×600 字号放大场景中检查了滚动、焦点、长文案与操作区，笔记/项目弹框在 800×600 下检查头尾。
- 本轮按 1.5 倍放大 15 个 Typography Token，并以 960×600、800×600 CSS 视口检查 16 个页面；隔离无头 Chrome 的缩放快捷键不改变布局缩放，因此通过有效 CSS 视口宽度及字体 Token 放大模拟桌面 150% 字体场景。两种视口均无页面级横向溢出，页头操作组可换行收纳，按钮文字无剪裁。
- 长文本复核使用 41 字任务标题和 89 字描述；标题输入保持单行可横向滚动，描述可换行和内部滚动，页面宽度及操作按钮未溢出。设置页三项同步操作在 800×600 下仍可容纳且按钮维持 44px。
- 发现弹框内焦点控件会落到吸底操作栏后，且操作栏下方露出表单文字；给 `.modal-card` 增加上下 `scroll-padding`，给 `.modal-actions` 扩展底部表面。任务表单实测 Tab 到状态、优先级、日期和标签时，焦点框完整位于固定页眉/操作栏之间；取消/保存按钮在 320px 下纵向排列且完整可见。
- P3 汇总已完成：8 大维度和 17 项验收状态均已记录在下方表格；标为“部分”或“待复核”的项目属于后续复核项，不影响本轮总结完成。
- 尚未解决的例外：设置页“保存设置”按钮位于页头，滚动到页尾时不可见；下拉/浮层裁切、其余弹框类型、窄高窗口非弹框页脚及软键盘遮挡尚未覆盖；深浅主题的全页面对比度、字重层次和间距特例仍需视觉复核；跨平台一致性尚未在其他运行目标确认。日程周视图在面板内横向滚动属于有意设计。
- 本轮静态检查 `git diff --check` 通过；按工作区要求不运行构建或测试。

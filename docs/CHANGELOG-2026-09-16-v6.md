## 4. 核心实现

- `BackupSchedule` 使用 `manual`、`daily`、`weekly` 三个稳定配置值；旧配置缺少该字段时默认 `manual`。
- `backup::maybe_create_auto` 根据最近备份的文件时间判断间隔，首次启用或超出间隔时创建备份。
- 应用启动打开 Workspace 后执行自动备份；备份失败只记录错误，不阻止应用启动。
- 备份清理从原来的“保留固定数量”调整为“保留配置天数”，并始终保护本次新备份和恢复安全备份。
- 月视图按周一至周日渲染 42 个日期格，灰显相邻月份日期，单日展示最多 4 个事件并提示剩余数量。

## 5. 用户可用功能

- 设置 → 本地备份：选择手动、每日或每周自动备份。
- 设置 → 本地备份：选择备份保留 7、30 或 90 天。
- 日程 → 月：使用左右按钮切换月份；点击日期新建日程，点击事件进入编辑。
- 原有“创建备份”和“恢复”入口保持不变。

## 6. 配置说明

- 配置字段：`sync.backupSchedule`，值为 `manual`、`daily` 或 `weekly`。
- 配置字段：`sync.backupRetention`，本轮按“天数”解释，默认值仍为 7。
- 自动检查发生在应用启动时，不创建后台常驻定时任务；应用未启动期间不会即时创建备份。

# 2026-10-12 开发变更记录（界面统一）

## 1. 修改概述

- 按优先级统一页面操作按钮的高度、圆角、颜色和键盘焦点样式，并扩大常用图标操作的点击区域。
- 移除页面 1080px 的最小宽度限制；窗口最小尺寸调整为 720×560，并为窄窗口增加侧栏收缩、单列内容和表单换行布局。
- 统一创建、编辑、知识库、命令面板及确认弹框的表面、暗色主题和滚动标题/操作区样式。
- 将删除、恢复、目录重命名等系统原生确认框替换为应用内对话框，支持确认队列、键盘关闭、焦点循环和焦点返回。
- 为页面、表单和弹框补充语义色、间距、字号、圆角、控件尺寸及层级变量。

## 2. 需求来源

### 用户需求

检查并统一所有页面、弹框和按钮的视觉风格，并按优先级处理发现的问题。

### 处理顺序

1. 先处理小窗口下内容挤压及常用按钮点击区域偏小。
2. 再统一弹框、命令面板、暗色主题、表单焦点和键盘操作。
3. 最后补齐公共设计变量并收敛各页面常用控件样式。

- 常用操作按钮、弹框表面、危险操作和键盘焦点已有统一基础规则。

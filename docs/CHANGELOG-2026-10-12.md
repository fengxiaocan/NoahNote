# 2026-10-12 开发变更记录

## 1. 修改概述

- 修复顶部搜索结果被当前页面遮挡的问题，并限制结果面板高度、允许面板内部滚动。
- 新增“归档空间”，集中查看任务、项目、清单、笔记、日程、模板、收件箱条目和知识库节点等归档内容。
- 在常用内容编辑区增加个人/工作空间一键切换入口；知识库目录切换时会连同子目录和页面一起移动。
- 归档内容可恢复，恢复知识库节点时会先恢复已归档的父目录。
- 沿用现有归档状态和工作区数据结构，没有新增数据库迁移。

## 2. 需求来源

### 用户需求

1. 归档的任务、清单如何找回。
2. 顶部搜索后，搜索内容与当前页面叠在一起。
3. 项目、清单、笔记、知识库等内容可在个人空间与工作空间之间一键切换。
4. 增加归档空间，查看所有已归档的任务清单等内容。

### 目标结果

- 搜索结果显示在页面内容上方，不再与页面内容混叠。
- 用户可在侧边栏进入归档空间，按内容类别筛选，并恢复条目。
- 用户可从内容编辑区直接将条目移到另一个空间。

## 4. 核心实现说明

### 修改前

- 搜索结果浮层的层级低于页面中部分内容，结果列表也没有最大高度和内部滚动。
- 应用没有集中查看已归档内容的页面。
- 多类内容没有直接的空间切换操作。

### 修改后

- 顶部栏建立明确的层叠层级，搜索面板位于顶部栏内部更高层，并限制高度、启用纵向滚动。
- 导航新增归档空间。打开时列表接口包含归档记录，页面按记录的 `archived` 状态过滤，支持按类别查看和恢复。
- 各内容编辑区通过共用按钮调用现有更新接口切换空间。知识库页面移到目标空间根目录；知识目录迁移会携带其子目录和页面。PDF 文件会同步移动到目标空间目录，并更新索引。

### 为什么这样实现

归档数据已有状态字段和恢复命令，因此归档空间直接复用现有数据模型。空间切换复用内容更新流程；需要移动文件的 PDF 和知识库目录由 Rust 仓库层处理文件及索引。

### 为什么没有采用其他方案

当前选择沿用现有归档字段、更新接口和本地工作区布局。该实现不需要增加归档专用表、空间映射表或数据库迁移。

## 5. 关键函数说明

### `reload`（`src/App.tsx`）

- 作用：根据当前页面加载数据；归档空间开启归档记录查询。
- 输入：当前 `activePage` 和 `space` 状态。
- 输出：更新应用内各内容列表。
- 调用关系：页面导航变化及操作成功后触发。
- 注意事项：归档记录只在归档页的查询结果中加载，常规列表继续沿用原过滤。

### `moveKnowledgeFolderToSpace` / `moveKnowledgeNodeToSpace`（`src/App.tsx`）

- 作用：切换知识目录或页面所属空间；目录操作清理可能失效的子页面选择。
- 输入：知识库节点和目标空间。
- 输出：迁移后的节点或更新操作结果。
- 调用关系：知识库页面操作和归档空间的迁移按钮。
- 注意事项：知识页面切换空间时移动到目标空间根目录；目录切换会移动整个子树。

### `restoreKnowledgeNode`（`src/App.tsx`）

- 作用：恢复知识页面或目录；如果父目录已归档，会先按从上至下的顺序恢复父目录。
- 输入：已归档的知识库节点。
- 输出：恢复后的节点。
- 调用关系：归档空间的恢复按钮。
- 注意事项：每个恢复步骤仍通过现有知识库更新接口写入。

### `move_document_space`（`src-tauri/src/workspace/repository.rs`）

- 作用：迁移 PDF 文件、元数据及语义索引到目标空间。
- 输入：文档 ID 和目标空间。
- 输出：更新后的 PDF 文档记录。
- 调用关系：Tauri 命令 `move_document_space`，由前端 PDF 文档编辑区调用。
- 注意事项：遇到目标路径冲突时返回验证错误；更新失败时尝试恢复原文件和元数据。

### `move_knowledge_folder_space`（`src-tauri/src/workspace/repository.rs`）

- 作用：迁移知识目录及其子目录、页面，并重建双链索引。
- 输入：目录 ID 和目标空间。
- 输出：迁移后的根目录记录。
- 调用关系：Tauri 命令 `move_knowledge_folder_space`，由知识库和归档空间调用。
- 注意事项：目标空间存在同名未归档页面或目录时拒绝迁移。

## 7. 影响范围分析

### 直接影响

- 顶部全局搜索、侧边栏导航、归档页面和内容编辑页面。
- Tauri 本地工作区内 PDF 文件和知识库目录的迁移流程。

### 间接影响

- 归档页打开期间会加载归档记录；侧边栏收件箱计数会排除已归档项目。
- 空间切换后，常规列表按当前空间重新加载。

### 风险点

- PDF 文档目前没有归档状态，仍沿用回收站删除流程；本次支持 PDF 空间迁移，不将 PDF 列入归档空间。
- 知识库目录迁移涉及多个文件和数据库记录；虽然会预检目标名称并更新搜索/双链索引，仍建议在桌面应用中验证实际工作区数据。

### 兼容性

- 未修改现有实体字段或数据库 schema；已归档数据继续使用原状态字段，现有常规列表默认不包含归档项。
